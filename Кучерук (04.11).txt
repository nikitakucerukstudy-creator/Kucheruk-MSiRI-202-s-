1. Collision (Коллизия)
Коллизия — это физическое столкновение двух игровых объектов. При столкновении Unity получает информацию о точке контакта, скорости движения и объекте, с которым произошло взаимодействие.
2. While (Цикл с предусловием)
While — цикл, в котором сначала проверяется условие, а затем выполняется код. Если условие истинно, команды повторяются. Если условие ложно, цикл не запускается или завершается.

3. Do-While (Цикл с постусловием)
Do-While — цикл, в котором сначала выполняется код, а затем проверяется условие. Если условие истинно, выполнение повторяется. Код обязательно выполняется хотя бы один раз.
3) GET - используется для получения данных с сервера.
POST - используется для отправки новых данных на сервер.
PUT/PATCH  обновление существующих данных на сервере.
DELETE  удаление данных с сервера.
4) OnCollision — используется для обработки физических столкновений объектов. Например, при столкновении мяча со стеной или падении предмета на поверхность. Для работы необходимы Collider и Rigidbody.
OnTrigger — применяется для определения пересечения объектов без физического отталкивания. Для этого у одного из коллайдеров включается параметр Is Trigger. Например, при подборе монеты или входе в игровую зону.
5) Input — система считывания действий игрока. Она позволяет обрабатывать нажатия клавиш клавиатуры, движения и клики мыши, нажатия кнопок геймпада и касания сенсорного экрана.
